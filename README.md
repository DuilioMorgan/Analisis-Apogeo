Proyecto Apogeo - Analisis de Datos de Empuje de Motor

Para ejecutar el software de manera correcta siga estos pasos:
Descargue todos los archivos adjuntos de Teams y guárdelos juntos dentro de una misma carpeta nueva.

Abra la terminal apuntando a esa carpeta.

Verifique tener las librerías (pip install streamlit pandas numpy matplotlib).

Arranque la interfaz web ejecutando el archivo principal con el comando:
streamlit run app.py


Aplicación de __init__
El archivo logica_motor.py contiene la Programación Orientada a Objetos (la Clase y el método __init__) para el procesamiento de datos.

El archivo app.py contiene la interfaz gráfica y llama a la lógica automáticamente.

Se incluye el DATOS.csv para la prueba.

Utilización de GitHub:
Decidimos utilizar GitHub para cargar los archivos de código con fines de entregarle los archivos en un solo link. 

Al igual que pueda visualizar la arquitectura y modulacion del codigo sin necesidad de descargar los archivos como tal.

Aplicación de la libreria streamlit:
Se utilizó la libreria streamlit como recomendación de usted, para poder crear una correcta visualizacion del programa.

A su vez, se utilizo para poder tratar con diferntes variables. Tanto como poder poner diferentes archivos .csv, como para poder ingresar las diferentes masas del propelente.
